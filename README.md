# Calendar

React-компонент `Calendar` — календарь месяца с материальной шапкой: день недели, число, месяц в родительном падеже и год, плюс сетка месяца с добивкой датами соседних месяцев.

![Внешний вид компонента](./assets/preview.png)

## Быстрый старт

```bash
git clone https://github.com/sun-fog/ra_components_calendar.git
cd ra_components_calendar
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка для продакшена: `npm run build`, предпросмотр сборки: `npm run preview`.

## Описание компонента

Компонент принимает один проп `date` — объект `Date`, который считается текущей датой.

| Блок | Что отображает |
| --- | --- |
| `ui-datepicker-material-day` | День недели по-русски («Среда») |
| `ui-datepicker-material-day-num` | Число месяца |
| `ui-datepicker-material-month` | Месяц в родительном падеже («марта») |
| `ui-datepicker-material-year` | Год |
| `ui-datepicker-month` / `ui-datepicker-year` | Месяц в именительном падеже («Март») и год в заголовке таблицы |

## Особенности реализации

- Сетка считается на чистом `Date`, без moment.js.
- Сдвиг первой недели: `(getDay() + 6) % 7` — неделя начинается с понедельника.
- Число дней в месяце: `new Date(year, month + 1, 0).getDate()`.
- Добивка датами соседних месяцев получает класс `ui-datepicker-other-month`.
- Дата из пропа выделяется классом `ui-datepicker-today`.
- Выходные (Сб, Вс) подсвечиваются через `colgroup` с классом `ui-datepicker-week-end`.
- Дни недели в шапке таблицы выводятся через `.map()` из массива.

## Проверка граничных случаев

Замените дату в `src/App.jsx`:

- `new Date(2020, 1, 29)` — високосный февраль;
- `new Date(2017, 11, 8)` — декабрь, добивка уходит в январь следующего года;
- `new Date(2018, 6, 15)` — июль 2018, начинается с воскресенья.
